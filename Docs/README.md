## 文档同步规则

1. 原理图修改后，同步 `硬件设计.md`、BOM 风险、DRC 状态和必要的测试项。
2. GPIO、Kconfig、固件路径或命令变化后，同步 `软件仓库.md`、`测试方案.md` 和相关 README。
3. 烧录工具参数变化后，以本地 `hisiflash --help` 为准，并同步烧录与串口监控示例。
4. 文档中的工程名统一为 `BS21_1/Board1/P1/PCB1`。
5. 生成型 PDF 不作为 Markdown 文档的权威源；Markdown 是可维护源文件。
