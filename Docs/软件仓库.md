## 核心应用

### sle_measure_dis（单链路测距）

Server/Client 模式，使用 SLE Channel Sounding IQ 测量两点距离。

测距链路：
1. SLE 建链后启用 Channel Sounding
2. CS 回调输出本端 IQ 报告，按 timestamp_sn 与 report_idx 聚合完整 IQ 帧
3. 一端通过 SSAP 把本端 IQ 传给另一端
4. 测距端检查本地/远端 IQ 时间戳匹配
5. 调用 `slem_alg_calc_smoothed_dis()` 计算距离
6. 应用层线性校正：`corrected = 0.7079 * measured - 0.1938`

关键参数：
- `TOF_DEFAULT = 2070`
- `DIS_ALG_MODE = 6`（V3 测距算法变体）
- `DIS_ALG_CALIB_VAL = 0.0f`

关键文件：
- `sle_measure_dis_server/sle_measure_dis_server_alg.c`
- `sle_measure_dis_client/`

### sle_locate（多基站定位）

1 Tag + 最多 4 Anchor 的星闪定位系统。

角色划分：
- **Anchor：** 固定基站，SSAP Server 广播。接收 Tag IQ，结合本地 IQ 计算距离，通知 Tag。
- **Tag：** 移动标签，SSAP Client 扫描连接多个 Anchor。维护连接、属性句柄和 IQ 缓冲。收到各 Anchor 距离后执行定位解算。

定位算法：
- 以 ANC0 为参考，消去非线性项，构建线性方程组 `A * p = b`
- 最小二乘解：正规方程 `(A^T A) p = A^T b`
- 2D 模式：2x2 Cramer 法则
- 3D 模式：3x3 Gauss-Jordan 消元
- 输出残差 RMS 作为质量指标

GTTT 调度：
- `enlarge_ratio = Anchor 数量`
- `sched_order = Anchor 槽位`
- 槽位绑定 MAC 表，断连重建不扰乱其他链路

默认 Anchor 几何（Kconfig 配置）：

| Anchor | X/mm | Y/mm | Z/mm | MAC 末字节 |
| --- | ---: | ---: | ---: | --- |
| ANC0 | 0 | 0 | 2558 | 0x01 |
| ANC1 | 4000 | 0 | 2665 | 0x02 |
| ANC2 | -2310 | 5040 | 2686 | 0x03 |
| ANC3 | 1050 | 4000 | 1250 | 0x04 |

关键文件：
- `common/sle_locate_common.h`：公共 UUID、消息格式
- `anchor/sle_locate_anchor.c`：Anchor 广播和连接管理
- `anchor/sle_locate_anchor_alg.c`：Anchor 端测距算法
- `tag/sle_locate_tag.c`：Tag 扫描连接和调度
- `tag/sle_locate_trilateration.c`：2D/3D 定位求解器
- `Kconfig`：角色、MAC、Anchor 数量和坐标配置

## 构建方式

```bash
# 单次构建
cd sle_local/src
python3 build.py -c standard-bs21e-1100e

# Kconfig 图形配置
python3 build.py -c standard-bs21e-1100e menuconfig

# 批量构建定位固件（tag + anchor0-3）
cd sle_local
python3 tools/build_locate_firmwares.py --num-anchors 4

# 仅构建部分角色
python3 tools/build_locate_firmwares.py --only tag anchor0 anchor1
```

## 烧录方式

1. 安装 CH341SER 驱动
2. Type-C 连接板卡（USB-to-TTL 芯片 --> TX/RX 测试点）
3. 打开 BurnTool，选择 `bs21e_all_in_one.fwpkg`
4. 勾选 Auto Burn 和 Auto Disconnect，点击 Connect
5. 按开发板 RST 按键启动烧录
6. 烧录完成，串口 115200 baud 查看日志

详细步骤见 `tools/WSL子系统编译及烧录.md`。

## 实验数据

数据源：`output/measurements_v3_v4.csv`
- 样本数：90,526
- 距离点：0.5m / 1.0m / 1.5m / 2.0m / 2.5m / 3.0m / 3.5m
- 会话数：8
- 算法：V3，DIS_ALG_MODE = 6

关键结论：
- V3 原始距离在所有测试点存在系统性高估（Bias +0.2m ~ +1.7m）
- 线性校正可压低偏差但非根本解决，需标定 TOF_DEFAULT 和每 Anchor bias
- 1.5m 和 3.5m 存在相位解模糊双峰问题

## 外设驱动模块 (`peripheral/`)

`v0.2.0` 新增完整的外设驱动框架，所有模块通过 Kconfig 开关条件编译：

| 模块 | 文件 | Kconfig | GPIO | 功能 |
| --- | --- | --- | --- | --- |
| 电池 ADC | `sle_locate_adc.c/h` | `SLE_LOCATE_ENABLE_ADC` | GPIO_02/AIN0 | CR2032 电压采集与电量估算 |
| 蜂鸣片 PWM | `sle_locate_buzzer.c/h` | `SLE_LOCATE_ENABLE_PWM` | GPIO_06 | 4kHz PWM 驱动，开/关/定时鸣叫 |
| NFC Tag | `sle_locate_nfc.c/h` | `SLE_LOCATE_ENABLE_NFC` | NFC1/NFC2 | NFC-A Tag 模拟，NDEF 配置，场检测 |
| I2C | `sle_locate_i2c.c/h` | `SLE_LOCATE_ENABLE_I2C` | GPIO_14/SCL, GPIO_15/SDA | 100kHz 主机，寄存器读写，总线扫描 |
| 按键 | `sle_locate_button.c/h` | `SLE_LOCATE_ENABLE_BUTTON` | GPIO_25 | 短按/长按/双击，去抖动，ISR 回调 |
| 功耗管理 | `sle_locate_pm.c/h` | `SLE_LOCATE_ENABLE_PM` | — | IDLE/LIGHT/DEEP 睡眠，电量缓存，空闲超时 |
| 板级定义 | `sle_locate_board.h` | 始终包含 | 全部 | 引脚映射、ADC 分压比、PWM 频率 |

Tag 固件推荐 Kconfig 配置：
```
CONFIG_SLE_LOCATE_ENABLE_ADC=y
CONFIG_SLE_LOCATE_ENABLE_PWM=y
CONFIG_SLE_LOCATE_ENABLE_NFC=y
CONFIG_SLE_LOCATE_ENABLE_BUTTON=y
CONFIG_SLE_LOCATE_ENABLE_PM=y
```
