# 基于 BS21 星闪的室内协同定位系统 — 焊接与调试指南

**适用 PCB**: PCB1 (Board1)  
**主控**: BS21E (hi2821, QFN-48)  
**供电**: CR2032 (3V)  
**参考手册**: `Docs/BS2XV100 硬件指南_02.pdf`  
**最近更新**: 2026-06-08

---

## 焊接总原则

1. **由电源到核心, 由核心到外设** -- 每焊完一个功能模块就上电测试, 避免大面积焊接后排查困难。
2. **QFN 焊接**: 建议使用钢网或拖焊工艺, 确保 EPAD 充分接地。EPAD 接地不良会导致芯片工作不稳定、BUCK 异常、RF 性能差。
3. **0402 器件**: 先焊一端固定, 再焊另一端; 电容电感注意不要用万用表电阻档在线测量, 避免误导通。
4. **静电防护**: BS21 是 CMOS 器件, 焊接操作台需接地, 人体需戴静电手环或触摸接地金属后再拿芯片。
5. **L1 确认**: L1 是 **2.2uH 功率电感** (DCC-DEC4 BUCK 回路), 不是电容, 也不是磁珠。电流能力需 >1.2A, DCR <0.3Ω。

## 第一阶段: 电源与供电 (已焊好)

用户已完成此阶段焊接。

### 已焊接器件
- BT1 (CR2032 电池座)
- U2 (AO3401 PMOS)
- U7 (100uF 钽电容, TMCMA0J107MTRF)
- C2 (100nF), C5 (1uF), C8 (4.7uF) -- SLE_3V3 去耦
- R17 (1M, PMOS Gate 下拉)
- R9 (1k), R16 (10k), Q3 (S8050), BUZZER2 -- 蜂鸣器驱动

### 第一轮测试: 电源检查
1. 万用表测量 TP8 (VBAT) 与 GND (TP6): 应读到 **3.0V~3.2V** (新电池)
2. 万用表测量 TP7 (SLE_3V3) 与 GND: 应读到 **接近 VBAT 电压** (因 PMOS 导通后压降约几十 mV)
3. 若 SLE_3V3 电压明显低于 VBAT (如 0V 或 1V 以下):
   - 检查 AO3401 方向: D=VBAT, S=SLE_3V3, G→R17→GND
   - 检查 R17 是否 1M, Gate 电压是否为 0V (GND)
   - 检查电池座正负极是否焊反
   - 检查 U7 100uF 电容是否短路
4. 短按/触发蜂鸣器 (PIEZO_PWM 节点对 GND 短接): **蜂鸣片应发声**, 说明蜂鸣器通路和供电正常

## 第二阶段: BS21 最小系统

焊接顺序: 先焊 U1 和去耦电容 → 再焊晶振 → 再焊电感 → 上电测试。

### 待焊接器件

| 位号 | 器件 | 封装 | 备注 |
| --- | --- | --- | --- |
| U1 | hi2821 (BS21E) | QFN-48 | 主控芯片, EPAD 必须良好接地 |
| C1 | 1uF | 0402 | DEC1 去耦 |
| C3 | 4.7uF | 0402 | DEC2 去耦 |
| C4 | 1uF | 0402 | DEC3 去耦 |
| C6 | 2.2uF | 0402 | MIC_LDO 去耦 |
| C7 | 10uF | 0402 | DEC4 去耦 (BUCK 输出) |
| **L1** | **2.2uH 功率电感** | 0402/0603 | **DCC-DEC4 BUCK 电感, 不是电容** |
| X1 | 32MHz 晶体 | SMD2016-4P | CL=8pF, X201632MKD4SI |
| C9 | 39pF | 0402 | XC2 串接电容 |

### 焊接步骤

1. **焊 U1**: 
   - PCB EPAD 上先上适量锡浆或焊锡, 热风枪 300-350C 吹平 EPAD
   - 对齐 U1 (注意 Pin1 标记), 热风枪均匀加热至引脚锡融化
   - 或用烙铁拖焊: 先固定对角, 再拉锡拖焊所有引脚
   - 用万用表测 VDD1(VBAT)/VDD2(SLE_3V3)/GND 之间无短路

2. **焊去耦电容 C1/C3/C4/C6/C7**:
   - C1 靠近 U1 Pin1 (DEC1)
   - C3 靠近 U1 Pin32 (DEC2)
   - C4 靠近 U1 Pin33 (DEC3)
   - C6 靠近 U1 Pin44 (MIC_LDO)
   - C7 靠近 U1 Pin46 (DEC4)

3. **焊 L1 (2.2uH 功率电感)**:
   - L1 连接 U1 Pin47 (DCC) 与 U1 Pin46 (DEC4)
   - 注意: L1 与 C7 都连接 DEC4, 布局要短宽
   - **确认 L1 不是磁珠, 不是 0R 电阻, 是 2.2uH 功率电感**

4. **焊晶振 X1 和 C9 (39pF)**:
   - X1 Pin2/Pin4 接地, Pin1→XC1(U1.Pin34), Pin3→C9→XC2(U1.Pin35)
   - C9 串在 XC2 与 X1 Pin3 之间, 不是到 GND
   - 晶振靠近 U1, 走线尽量短

### 第二轮测试: 最小系统上电

1. 装电池, 万用表测量:
   - TP7 (SLE_3V3): ~3V
   - U1 Pin48 (VDD1): ~3V
   - U1 Pin36 (VDD2): ~3V
   - U1 Pin13 (VDDIO1): ~3V
   - **重点**: U1 Pin46 (DEC4) 对 GND 应测得 ~1.2V~1.8V (BUCK 输出电压)
   - **若 DEC4 为 0V 或等于 VBAT**: BUCK 未工作, 先检查 L1 是否 2.2uH 电感, DCC/DEC4 是否焊接良好, 有无短路

2. 万用表测 U1 Pin1 (DEC1): 应 ~1.2V (内部 LDO 输出)
3. 万用表测 U1 Pin33 (DEC3): 应 ~1.2V (时钟电源)
4. **手感温度**: U1 不应明显发热 (<40C)。若发烫: 检查 EPAD 接地、有无短路、L1 是否正确

5. 用示波器/逻辑分析仪测 X1 (XC1/XC2引脚): 应看到 **32MHz 振荡波形**, 幅度约 0.8V~1.2V pk-pk
   - 若无振荡: 检查 C9 是否 39pF, X1 是否焊好, 晶体 CL 是否为 8pF
   - 若有振荡但频率偏差大: 可能 C9 值不对或晶体 CL 不匹配

## 第三阶段: 调试接口

焊接 SWD + UART 串联电阻和测试点, 以便连接调试器/烧录器。

### 待焊接器件

| 位号 | 器件 | 封装 | 备注 |
| --- | --- | --- | --- |
| R1 | 100R | 0402 | SWDIO 串联 |
| R2 | 100R | 0402 | SWDCLK 串联 |
| R3 | 100K | 0402 | SWDIO 下拉 (可选, 看烧录兼容性) |
| R4 | 100K | 0402 | SWDCLK 下拉 |
| R10 | 100R | 0402 | NRST 串联 |
| R11 | 100R | 0402 | UART_TXD 串联 |
| R12 | 100R | 0402 | UART_RXD 串联 |

### 第三轮测试: 连接调试器

1. 连接 JLink/DAP-Link 等 SWD 调试器:
   - SWD_CLK (TP3) → 调试器 SWCLK
   - SWD_DAT (TP2) → 调试器 SWDIO
   - TP7 (SLE_3V3) → 调试器 VREF (电平参考, 重要!)
   - TP6 (GND) → 调试器 GND
   - NRST (TP1) → 调试器 nRESET (可选)

2. **调试器 VREF 连接说明**: SLE_3V3 随电池电压变化 (1.8V~3.2V), 调试器必须以此作为 IO 电平参考。**不要用外部 3.3V 固定电压作为 VREF**, 否则电池低压时调试器推挽电压高于芯片 IO 耐压。

3. 调试器软件尝试识别芯片:
   - 使用 SEGGER J-Link / pyOCD / OpenOCD
   - 应能识别到 ARM Cortex-M 内核 (BS21 使用 ARM 内核)
   - 若能识别: 最小系统 + 调试接口工作正常
   - 若不能识别: 
     - 检查 SWD 线序和焊接
     - 测量 SLE_3V3 是否正常供电
     - 检查 NRST 是否悬空或被拉低
     - 检查晶振是否起振

4. **UART 回环测试** (可选):
   - 短接 TX 测试点与 RX' 测试点
   - 调试器 UART_TXD 发数据, UART_RXD 应收到回环数据
   - 验证 UART 通路焊接

## 第四阶段: RF 与天线

### 待焊接器件

| 位号 | 器件 | 封装 | 备注 |
| --- | --- | --- | --- |
| R8 | 0R | 0402 | RF 串联 (芯片侧) |
| R5 | 0R | 0402 | RF 串联 (天线侧) |
| C11 | NC (不焊) | 0402 | 天线侧对地电容位, 保留空位 |
| C12 | NC (不焊) | 0402 | 芯片侧对地电容位, 保留空位 |
| ANT1 | 板载天线 | -- | 2.4G 板载天线 |

### 焊接步骤
1. 先焊 R8 (0R) 和 R5 (0R), 使 RF 链路直通
2. C11/C12 保留不焊 (NC), 留作匹配调试
3. ANT1 按 PCB 布局焊接, 天线区域避免被螺丝/外壳/电池遮挡

### 第四轮测试: RF 基本检查

1. 用万用表二极管/电阻档测:
   - RF_ANT (U1 Pin30) 对 GND → 不应短路 (应为高阻)
   - 确认 R8/R5 通路焊接
   
2. 建议 EVT 阶段用 VNA 或频谱仪:
   - 测量天线端口的 S11
   - 目标 S11 < -10dB

### 调测
- 使用网络分析仪或 NFC 测试卡检查 13.56MHz 谐振
- 调整 C13/C14 使谐振点接近 13.56MHz
- NFC 线圈区域禁止铺铜和金属遮挡

## 第六阶段: ADC 电池分压

### 待焊接器件

| 位号 | 器件 | 封装 | 备注 |
| --- | --- | --- | --- |
| R14 | 2M | 0402 | BAT_ADC 分压上臂 |
| R15 | 1M | 0402 | BAT_ADC 分压下臂 |
| C_bat | 10nF (预留, 可选) | 0402 | BAT_ADC 对地滤波 |

### 测试
1. 装电池, 万用表测 BAT_ADC 节点对 GND 电压
2. 验证分压比: BAT_ADC ≈ SLE_3V3 * (1/3)
3. 软件侧后续通过 ADC 采样换算电池电压: `VBAT = ADC_value * 3`

## 常见问题排查

| 现象 | 可能原因 | 排查方法 |
| --- | --- | --- |
| SLE_3V3 = 0V | 电池座虚焊, AO3401 方向焊反, U7 短路 | 测 BT1 + 端电压, 测 AO3401 D/S/G 电压 |
| SLE_3V3 明显低于 VBAT (>0.3V 压降) | AO3401 未完全导通, R17 虚焊 | 测 AO3401 G 电压 = 0V? VGS 是否为负? |
| DEC4 = 0V | L1 虚焊, L1 不是电感是磁珠/0R, U1 BUCK 异常 | 确认 L1 为 2.2uH 功率电感, 测 DCC-DEC4 通路 |
| DEC4 = VBAT | BUCK 未工作, L1 短路/磁珠 | L1 必须是功率电感, 非磁珠非 0R |
| U1 发烫 | EPAD 未接地, VDD/GND 短路 | 检查 EPAD 焊接, 测 VDD-GND 阻抗 |
| 32MHz 不起振 | C9 焊错位置 (对地? 应串接), X1 CL 不匹配, X1 虚焊 | 确认 C9 串在 XC2 与 X1 间, 检查晶振型号 |
| SWD 无法识别 | SLE_3V3 未接 VREF, SWD 线序反, NRST 被拉低 | 测 SWD_CLK/DAT 到 U1 引脚通路, 测 NRST 电压 |
| RF 输出弱 | 天线净空不够, 匹配未调, L1 干扰 RF | 确认天线下方无铺铜, 检查 layout |
| NFC 读不到 | 谐振点偏, 线圈被金属遮挡 | 调 C13/C14, 确保线圈区域无金属 |

## 烧录说明

- 烧录方式: USB-to-TTL 转 UART_L0 (TX/RX/GND)，使用项目本地 `hisiflash`
- 烧录引脚: USB-to-TTL TX 接板卡 RX，USB-to-TTL RX 接板卡 TX，GND 接 TP6
- 电平: VDDIO1 (`SLE_3V3`) 为电平参考；CH340 TX 若为 3.5V，应使用分压/电平转换，避免向低电压 IO 注入电流
- 烧录参数: BS2X，推荐烧录波特率 460800；日志监控波特率 115200
- 烧录前: 确认最小系统供电正常、DEC4 正常、32MHz 振荡稳定
- 如需 SWD 仿真调试: 连接 JLink/DAP-Link 到 TP2(SWDIO)/TP3(SWDCLK)/TP1(NRST)/TP6(GND)/TP7(VREF)

```bash
./hisiflash/target/release/hisiflash \
  -c bs2x -p /dev/ttyUSB0 -b 460800 \
  flash sle_local/src/output/bs21e/fwpkg/standard-bs21e-1100e/bs21e_all_in_one.fwpkg \
  --monitor --monitor-baud 115200
```
